# A-09 决策记录：是否需要存货与存货跌价准备核算

> 需求书 **A-09** 的验收标准原文：*"产出『是否需要存货核算』的书面结论（由财务负责人签字），
> 若不需要则本项关闭。"* 本文即该书面结论。
>
> **本文由开发方（技术侧）起草，结论待财务负责人签字确认。**
> 未经签字前，A-09 在台账中保持"待决策"而非"已完成"。

## 1. 结论

**建议：本阶段不实现存货核算与存货跌价准备。** A-09 作为**决策项关闭**，
不产生开发工作量。

理由是本公司业务形态为**数据服务与项目交付**，不存在"采购存货 → 入库 → 销售出库"
这一链条（证据见第 3 节）。强行引入存货模块会带来持续的表结构、期末计价、
跌价测试与报表列报成本，而没有任何对应业务。

**但结论有一个前提**：若第 5 节列出的触发条件出现，本决策必须**重新评审**。

## 2. 需求书原描述与实测差异（需一并确认）

需求书现状描述为：*"`fin_account` 无 `1401 库存商品` 等科目"*。

**实测不符**：会计科目表中**已存在 `1403 原材料`**
（`is_leaf=1`、`account_type=asset`、方向借方）。但：

- **没有** `1401 库存商品`、`1402 在产品`、`1405 库存商品跌价准备`；
- `1403 原材料` 在全部凭证中的**使用次数为 0**；
- 数据库**没有任何**存货相关表（`%inventory%` / `%stock%` / `%goods%` 均为 0 张）；
- 全部 39 个科目中 14xx 仅此 1 个。

请财务确认：`1403 原材料` 是建账模板带入的多余科目（建议停用/隐藏，
避免误用），还是确有零星物料采购需要保留？

## 4. 不做存货核算带来的具体处理口径（请一并确认）

以下几点是"不做存货"在账务上的**直接后果**，需财务确认可接受：

1. **数据集/数据产品**（`da_dataset`）按 **无形资产 / 长期待摊** 或当期费用处理，
   **不作为存货**。若属于对外销售的标准化产品，其开发成本如何归集需另行明确。
2. **交付物**（`erp_deliverable`，类型 `dataset/report/software/doc/other`）
   作为**项目交付成果**参与验收与结项，不进存货台账。
3. **外协成本**（`erp_project_cost.cost_type='outsource'` / `flex_labor`）
   按项目直接归集，**不经过存货中转**。
4. `1403 原材料` 科目：建议**停用**（`fin_account.status='inactive'`），
   保留历史数据不删除。若保留启用状态，需说明其实际用途。

## 5. 触发重新评审的条件

出现以下任一情形时，A-09 必须重新评审（届时工作量按需求书估 80–120 h 另行立项）：

- 公司开始**采购实物商品并转售**（出现货物采购发票、出入库行为）；
- 数据集/数据产品**标准化并批量交付**，形成"先生产后销售"的存货形态；
- 引入**生产过程**（在制品、半成品）而非纯服务交付；
- 外部审计或税务检查**要求**提供存货台账。
