# 全站 UI 问题审计与修复方案

> 审计时间：2026-10-19  
> 范围：1440 / 1280 两档，34 个路由  
> 结论：当前不是单个 `?` 的位置问题，而是**操作分组、表格列策略、页面模板**三类系统性问题的叠加。

---

## 0. 结论

`?` 只是一个显眼症状。真正的问题是：

1. **操作组没有容器**，`?` 被 flex 推到页面最右侧，和按钮失去视觉关系；
2. **表格列宽没有和内容区宽度联动**，1440/1280 下大量列被固定操作列盖住或裁掉；
3. **页面操作位置不统一**：有的在页头，有的在筛选条，有的在 Tab 下方；
4. **提示仍然堆叠**：税务页同时出现说明、黄色提示、红色提示；
5. **表格外框不统一**：客户表在卡里，合同/审计/财务表是裸表；
6. **次级操作过多**：合同/发票行内 4~6 个按钮，操作列挤压。

---

## 1. P0：表格列被裁切 / 被固定操作列盖住

### 现象

1440 合同表：

```text
合同编号 | 名称 | 客户 | 计费模式 | 金额 | 税率 | 操作
```

`状态 / 负责人 / 签订日期` 看不到；操作列固定在右侧，盖住了中间列。

1280 合同表只剩：

```text
合同编号 | 名称 | 客户 | 计费模式 | 操作
```

项目表 1440 只剩到「预算」，`进度 / 状态 / 开始日期` 被裁掉。资产表 1440 的「采购日期 / 折旧月数」被裁掉；财务应收、会计账簿同样在右侧被截断。

### 根因

- `scroll.x` 是手填值，普遍小于真实列宽总和；
- 固定 `fixed: 'right'` 操作列在窄容器里覆盖了普通列；
- 没有列优先级，所有列在所有宽度都强行渲染；
- 横向滚动条在 `y` 固定高度表格里落在底部，首屏看不到，用户不知道还能横向滚动。

### 修复

#### A. 列宽必须可计算

不要手填 `scroll.x`：

```ts
// 反例
scroll={{ x: 1300 }}

// 正例：按列定义求和，或直接 max-content
scroll={{ x: 'max-content' }}
```

有固定列的表格，建议：

```ts
const tableWidth = columns.reduce(
  (sum, col) => sum + (typeof col.width === 'number' ? col.width : 0),
  0,
);
scroll={{ x: tableWidth }}
```

#### B. 列优先级

合同表：

| 列 | 1440 | 1280 | 处理 |
|---|---|---|---|
| 编号/名称/客户/金额/状态 | 保留 | 保留 | 核心 |
| 计费模式/税率 | 保留 | 保留 | 窄列 |
| 负责人/签订日期 | 隐藏 | 隐藏 | 快速查看 Drawer 里看 |
| 操作 | 保留 | 保留 | 最多 2 个 + 更多 |

项目表：

| 列 | 1440 | 1280 |
|---|---|---|
| 编号/名称/合同 | 保留 | 保留 |
| 成交报价/项目经理/预算 | 保留 | 保留 |
| 进度/状态 | 保留 | 保留 |
| 开始日期 | 隐藏 | 隐藏 |

#### C. 操作列收敛

合同行：

```text
[查看] [详情] [⋯]
```

`编辑 / 找相似 / 转项目` 收进 `⋯`。  
发票行同理：

```text
[查看] [详情] [⋯]
```

`编辑 / 关联应收 / 作废 / 认证` 收进更多菜单；危险操作仍在菜单内二次确认。

#### D. 横向滚动提示

保留横向滚动的报表表（账簿、报表）增加：

```text
← 横向滚动查看更多 →
```

并在表格容器加细边框和右侧渐隐，提示还有列。

## 2. P0：`?` 与操作组脱节

### 现象

- 合同页 `?` 在「同步记录」右侧 30~40px，孤立在页面最右；
- 税务页 `?` 在「确认底稿」右侧，和两个按钮都不成组；
- 数据资产授权页 `?` 在筛选条最右，与「新增授权」不相邻；
- 1280 下 `?` 几乎贴页面右边缘，像悬浮图标。

### 根因

`ActionHelp` 直接挂在 `PageShell.actions` 的 flex 中：

```tsx
<div className="flex shrink-0 items-center gap-2">
  {actions}
</div>
```

它没有和按钮共用一个分组容器，`gap-2` + 32px 点击区使它看起来是独立图标。

### 修复：新增 `ActionGroup`

```tsx
<ActionGroup>
  <Button variant="outline">同步到多维表格</Button>
  <Button variant="outline">同步记录</Button>
  <ActionHelp title="同步与同步记录">…</ActionHelp>
</ActionGroup>
```

视觉：

```text
┌──────────────────────────────────────────────┐
│ [同步到多维表格] [同步记录] │ ? │
└──────────────────────────────────────────────┘
  圆角容器、1px 边框、8px 内边距、4px 间距
```

或更轻量：

```text
[同步到多维表格] [同步记录]  ? 
                             ↑ 与按钮同一基线，4px 间距
```

规则：

- 主操作不放进组；次级操作和 `?` 成组；
- 一个操作组最多一个 `?`；
- `?` 只解释同组动作；
- 手机/窄屏下 `?` 跟随组换行，不贴页边；
- `FieldHelp` 与字段 label 同一行，使用 `gap-1`，不是 `gap-0.5`。

## 3. P0：页面操作位置不统一

### 现象

- 合同/客户/项目：操作在 `PageShell.actions`；
- 财务应收/发票：操作在筛选条里；
- CRM：导出/新建在 Tab 下方独立一行；
- 资产：新增资产在筛选条最右；
- 审计：导出在筛选条里；
- 设置：无页头动作。

### 修复：固定页面模板

```text
PageShell
  PageHeader：标题 + 状态 + 主操作 + 次级操作组
  Tabs（可选）
  FilterBar：只放筛选 + 只读工具（导出/列设置）
  Table / Content
```

硬规则：

- **写操作**（新建/登记/导入）只在 PageHeader；
- **筛选**只在 FilterBar；
- **导出**可留在 FilterBar 最右，但必须与筛选同组；
- 不允许「写按钮夹在筛选控件中间」。

具体：

| 页面 | 动作迁移 |
|---|---|
| 应收应付 | 登记应收/登记回款 → 页头 |
| 发票台账 | 发票登记 → 页头；导出留在筛选区 |
| CRM | 新建线索/导出 → 页头 |
| 固定资产 | 新增资产 → 页头 |
| 审计 | 导出 CSV → 页头；筛选条只留筛选 |
| 税务 | 扫描/确认底稿 → 页头（保留） |

## 4. P0：税务页提示堆叠

### 现象

税务页同时有：

1. 「税务风险扫描」标题；
2. 两段说明文字；
3. 黄色提示：未指定纳税主体；
4. 红色提示：发票台账差异；
5. 六个指标卡；
6. 底稿表。

两个提示都在说「未指定纳税主体」，信息重复；红色提示块占据首屏。

### 修复

- 页面只保留一条 `NoticeBar`：

```text
未指定纳税主体，附加税费无法按主体计提；当前有 2 项口径差异。 [处理]
```

- 扫描说明移到 `ActionHelp`；
- 风险详情移到右侧 Drawer；
- 页面只显示风险摘要 chip；
- `0 行存在差异` 使用 **success**，不是 danger（目前红底红字，语义错误）。

## 5. P1：审计表仍展示原始 JSON

### 现象

审计表「详情」列直接显示 `{"method":"POST","path":"/api/...`，被截断；虽然已有 Drawer，表格仍然很脏。

### 修复

- 表格删除「详情」列；
- 改为「操作 / 模块 / 对象 / 时间 / 查看」；
- JSON 只在 640px Drawer 中展示；
- 筛选条压缩为一行，导出移到页头；
- 「防篡改校验」卡改为页头下方一条紧凑状态条，不占 160px。

## 6. P1：表格外框不统一

### 现象

- 客户表在白色圆角卡里；
- 合同/项目/审计/财务表直接铺在背景上；
- 空态高度、边框、分页位置不一致。

### 修复

二选一，全站统一：

**推荐：表格内容面**

```text
1px border + 12px 圆角 + 白色底
表头浅灰
分页在表格底部内侧
```

所有列表页使用同一个 `DataTableSurface` 包裹，不再每页手写 `div`。

## 7. P1：设置页空间失衡

### 现象

1440 下设置页 1024px 卡片里，输入框只有 256px，右侧大片留白；没有二级导航，三个 Tab 横向切换。

### 修复

```text
设置
├─ 左侧子导航 200：外观 / 品牌 / 飞书 / 字典 / 参数
└─ 右侧内容 720~880
    表单两列
```

- 卡片宽度 880；
- 字段两列；
- 保存按钮吸底或组内；
- 不再全宽卡片。

## 8. P1：报表重复表头

### 现象

财务报表「资产负债表」表头出现两个「年初余额」。

### 修复

- 找出重复列定义，第二个改为实际含义（如「年初余额」/「上年年末余额」）；
- 对报表列定义补一条单测，断言列 key 唯一、表头不重复。

## 9. P1：主按钮发光

### 现象

「登记合同」「新建」「项目立项」等主按钮带蓝色 glow，与细边框、低饱和内容面不协调。

### 修复

- 去掉 `shadow-brand` 或降为 `shadow-sm`；
- 主按钮只靠底色和字重，不靠光晕；
- 危险按钮同理，不用红色 glow。

---

## 10. P1：空态与提示文案

### 现象

- CRM 空态写「点击上方新建线索」但没有按钮；
- 多处空态只有一句说明，没有直接动作；
- 自动化任务描述含技术细节；
- 表单顶部说明和底部提示重复。

### 修复

- 空态统一：图标 + 一句 + **一个主操作按钮**；
- 自动化描述去掉「任务标识仅在排障时使用」；
- 页面 description ≤ 28 个汉字；
- 技术说明进 `ActionHelp` / `FieldHelp`。

## 11. P2：页头动作溢出

### 现象

1280 下合同页四个动作 + `?` 占满右侧，标题区域被压缩；再长一点的标题会碰按钮。

### 修复

- `PageShell` actions 支持 `flex-wrap`；
- 1280 下次级动作收进「更多」；
- 标题 `truncate`，`min-w-0`；
- 页头高度允许两行，但动作组不压标题。

---

## 12. P2：侧栏财务组密度

### 现象

财务 8 个菜单两列排列，文字 12px，无「资金/账务/报表」分层。

### 修复

```text
财务
  资金
    应收应付  票据管理
  账务
    预算费控  总账凭证  会计账簿
  报表
    财务报表  税务申报  期末年结
```

或保持 2 列，但加三行小标题；不要 8 个词挤成 4 行无分组。

## 13. P2：FieldHelp 与 label 结构

### 现象

`FieldHelp` 嵌在 `<div>` 里和 `FormLabel` 并排，`gap-0.5`，点击可能触发 label；视觉上问号紧贴文字。

### 修复

```tsx
<div className="flex items-center gap-1">
  <FormLabel>税率（%）</FormLabel>
  <FieldHelp label="税率">…</FieldHelp>
</div>
```

- gap 4px；
- 问号 14px，点击区 24px；
- 不要把按钮嵌在 `<label>` 内；
- 表单行高保持一致。

---

## 14. P2：抽屉/弹窗收口

### 现象

- Drawer 关闭按钮获得蓝色 focus ring，和内容不协调；
- 部分弹窗标题 16，部分 18；
- 弹窗底部按钮间距不统一。

### 修复

- Drawer/Dialog 共用 `SheetHeader` / `DialogFooter` 样式；
- 关闭按钮 `focus-visible:ring-2 ring-primary/30`；
- 标题固定 16/600；
- 底部按钮 8px 间距。

## 15. 修复顺序

### Phase 1：结构修复（P0）

1. `ActionGroup` + `ActionHelp` 重定位；
2. 页面操作位置统一：写操作回 PageHeader；
3. 表格列策略：合同/项目/资产/财务/账簿；
4. 税务页提示合并 + 风险 Drawer。

### Phase 2：列表统一（P1）

5. `DataTableSurface` 统一表格外框；
6. 操作列收敛到 2 个 + 更多；
7. 审计表删除 JSON 列；
8. CRM/资产/财务动作迁移。

### Phase 3：视觉收口（P1/P2）

9. 设置页左侧导航；
10. 报表重复表头；
11. 主按钮去 glow；
12. 空态/文案；
13. FieldHelp 结构；
14. 侧栏财务分组；
15. Drawer/Dialog 样式。

### Phase 4：验收

- 1440/1280 两档逐页截图；
- 表格无列被固定操作列盖住；
- `?` 与所属操作组左对齐、间距 ≤ 8px；
- 每页最多一条 NoticeBar；
- 无卡片套卡片；
- `type:check + lint + test + build`；
- Docker healthy。

## 17. 不做的事

- 不把提示全部改成弹窗；
- 不给每个按钮加 `?`；
- 不为所有表格写死更大的 `scroll.x` 后假装解决；
- 不通过隐藏所有列来“让页面不溢出”。
