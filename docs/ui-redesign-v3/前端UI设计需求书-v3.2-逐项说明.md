# 晟笙 ERP 前端 UI 设计需求书 v3.2

> 状态：设计需求，不改代码  
> 日期：2026-10-19  
> 本版只改「说明放在哪」。视觉、列表、弹窗宽度、一页一个主按钮，仍以 v3 第 6 至 8 节为准。

v3 把口径收进弹窗右上角的一个「说明」。纳税主体新弹窗已经按这个做了：表单干净，但看某一项时不知道它是什么意思，必须先打开总说明再自己对号。这不符合使用方式。

本版改为：**每一项自己的右上角解释这一项。** 覆盖全站所有「看名字不能直接填」的项，不限于纳税主体。

---

## 1. 要解决的问题

用户面对的是一项一项的控件，不是一篇总说明。

现在的纳税主体弹窗：

- 右上角有「说明」，关闭在它右边。
- 「城建税率」下面只有一句「未填写，附加税无法出数。」
- 「小型微利企业」选了「符合」之后，下面只有「所得额超过 300 万时仍按 25%。」
- 纳税人类型、两种默认税率、申报周期，旁边没有任何入口说明这项是什么。

一句结果不够。用户要问的是：**这一项到底是什么意思，我该怎么选。** 这个入口必须长在这一项上，而不是长在整张弹窗上。

以前的两种做法都不再用：

| 做法 | 为什么停 |
|---|---|
| 字段下面铺一整段说明 | 表单被说明撑高，星号还会原样显示出来 |
| 标签文字旁边贴一个 14px 的小 `i` | 太小，和标签粘在一起，不知道它属于哪一项 |
| 整页或整张弹窗只有右上角一个「说明」 | 解释的是这一屏，不是眼前这一项 |

## 2. 决定

说明锚在**这一项的右上角**。

一项是指用户会单独问「这是什么」的一块界面：

- 一个表单字段
- 一个指标卡
- 一个筛选条件
- 一个表头里看不懂的列
- 一个看名字看不出后果的按钮

```text
城建税率（%）                              (i)
[ 7、5 或 1                                 ]
未填写，附加税无法出数。
```

`(i)` 在这一项标签行的最右边，和下面控件的右边缘对齐。它属于这一项，不属于整张弹窗。

点开后只讲这一项，浮层从这项的标记下方打开，不跳到页面别处。

弹窗标题行和页面标题行**不再放总说明**。标题行只留关闭或页面操作。总说明会让人以为解释都在那里，从而找不到眼前这一项的意思。

## 3. 标记长什么样

| 项 | 要求 |
|---|---|
| 图形 | 16px 线框圆形，里面是 `i` |
| 点按区域 | 28×28，比图形大，方便点 |
| 位置 | 该项标签行的右端；没有标签的卡片，放在卡片右上角，距边 8px |
| 颜色 | 默认次要灰，白底圆，1px 浅边框 |
| 悬停 | 图形变为正文色 |
| 打开 | 只响应点击。悬停不打开，避免鼠标划过挡住输入 |
| 浮层 | 宽 280px，从标记下方向下、右对齐。超出屏幕时改为向上 |
| 关闭 | 再点标记、点外面、或按 Esc |
| 键盘 | Tab 能落到标记，Enter 或 Space 打开 |

同一项只有一个标记。标记和必填星号分开：星号跟在标签文字后面，标记在行的右端。

不需要解释的项不放标记。包括：姓名、备注、搜索框、取消、保存、关闭、普通的新建。

## 4. 点开之后写什么

每项固定三句，能短则短。先结果，后原因。

```text
城建税率
市区一般填 7，县镇 5，其他地区填 1。
留空不是 0。增值税附加税会拒绝出数，避免把没配置当成免税。
```

1. 这一项是什么。
2. 应该怎么填或怎么选。
3. 留空、选「未确认」或选错时，系统会怎样。

限制：

- 正文不超过 4 行。
- 不出现 `**`、`#`、反引号。
- 不写内部字段名，不写「本系统没有取数能力」这种实现说明，改写成用户能执行的话：「从业人数和资产总额需要你自己确认。」
- 选项本身保持短词。法定条件写在这项的浮层里，不写进下拉项，也不写进占位符。

字段下面仍只留**当前结果**，并且只在当前值会导致多缴、不出数或锁定期时出现。值一改，这句话跟着改或消失。它不是说明文档。

```text
未填写，附加税无法出数。
按 25% 计税，可能多缴。
所得额超过 300 万时仍按 25%。
```

校验错误仍在字段下，用危险色，一次只说这一项怎么改。

## 5. 纳税主体弹窗样板

这张弹窗作为全站表单的对照。标题行只有标题和关闭，没有「说明」。

| 项 | 标记 | 浮层要写的话 | 字段下的当前结果 |
|---|---|---|---|
| 编码 | 有 | 主体在系统里的唯一编号。创建后不能再改。 | 仅编辑时：「创建后不可修改。」 |
| 名称 | 无 | 名称本身就是意思 | 无 |
| 统一社会信用代码 | 有 | 开票和申报使用的 18 位代码。填错不影响保存格式以外的计算，但票面和申报会对不上。 | 无。格式不对时只显示错误 |
| 纳税人类型 | 有 | 决定销项和进项能选哪些税率。一般纳税人和小规模纳税人档位不同。切换后，两种默认税率回到该类型的默认档。 | 无 |
| 默认销项税率 | 有 | 开销项发票时默认带出的税率，仍可在单据上改。只能选当前纳税人类型允许的档位。 | 无 |
| 默认进项税率 | 有 | 登记进项发票时默认带出的税率。档位规则与销项相同。 | 无 |
| 城建税率 | 有 | 市区一般 7，县镇 5，其他 1。留空不是 0，附加税不出数。 | 仅空着时：「未填写，附加税无法出数。」 |
| 申报周期 | 有 | 只影响小规模纳税人的免征额度：按月 10 万，按季 30 万。未确认时不判断免征，可能多缴，不会少缴。一般纳税人保持未确认即可。 | 仅小规模且未确认：「未确认，不判断免征额度。」 |
| 小型微利企业 | 有 | 所得额不超过 300 万、从业人数不超过 300、资产总额不超过 5000 万，三项同时满足时实际税负 5%，否则 25%。从业人数和资产总额要人工确认。未确认按不符合。已选符合但所得额超过 300 万时，仍按 25%。 | 未确认：「按 25% 计税，可能多缴。」符合：「所得额超过 300 万时仍按 25%。」不符合：不显示 |

下拉短标签保持：未确认 / 符合 / 不符合，未确认 / 按月 / 按季。占位符只写 `7、5 或 1`。

## 6. 全站怎么覆盖

同一套标记用在四类东西上。不另做一套图标。

### 6.1 表单字段

凡是「填了会改变金额、税额、权限、期间或后续能不能改」的字段，都在该项右上角放标记。纯身份信息除了有不可逆规则的（如编码创建后不可改），不放。

下面按页面列出必须解释的项。实施时浮层按第 4 节写，不把下表原文直接铺到界面上。

**客户与合同**

| 页面 | 要解释的项 |
|---|---|
| 客户 | 信用额度：超额后新合同能不能提交 |
| 线索与商机 | 阶段：进入下一阶段要满足什么；赢单后生成什么 |
| 合同 | 纳税主体、税率、计费模式、付款条款。审批通过后金额和客户不能再改，因为发票和应收挂在原客户上 |
| 合同转项目 | 预算：转项目时带出的金额是哪一个 |

**项目交付**

| 页面 | 要解释的项 |
|---|---|
| 项目 | 最终成交报价、预算基线、预计总成本。三个数不是同一个数 |
| 成本 | 归集与分摊。分摊后原金额是否还能改 |
| 收入确认 | 确认收入和开票不是同一步。已确认未开票是什么 |

**采购与资产**

| 页面 | 要解释的项 |
|---|---|
| 采购 | 申请、订单、入库各自锁定什么 |
| 退货 | 退货和红冲、应付的关系 |
| 固定资产 | 残值、折旧月数、我方纳税主体、采购日期。折旧从哪一期开始，处置和减值有什么差别 |

**财务**

| 页面 | 要解释的项 |
|---|---|
| 应收 | 到期日：账龄从到期日算逾期；没有到期日算未逾期。核销：计入已结清，余额减少 |
| 应付 | 到期日、付款方式。付款申请和已付款不是同一状态 |
| 发票 | 方向、发票类型、含税金额、税率、关联应收。作废会释放可开票金额且不能恢复。查验、认证只改税务状态；没配查验服务时只记录状态 |
| 票据 | 登记、背书、贴现、托收各自把状态改成什么 |
| 预算费控 | 占用、发生、可用。费用申请和报销不是同一张单。我方纳税主体决定这张费用进哪个主体 |
| 凭证 | 过账和结账的差别。凭证必须有纳税主体，否则不进该主体的账簿 |
| 报表 | 每个报表页的期间、纳税主体、是否含未过账。口径不写在每个数字下；某个格子算不出时显示「—」，这个格子自己的标记或点击说明一句原因 |
| 账簿 | 余额方向、辅助核算 |
| 税务申报 | 底稿来源、扫描只检测不改数、确认底稿会锁定本期。缺城建税率、未确认申报周期、未确认小微资格时分别会怎样 |
| 期末年结 | 结转预览和执行年结不是同一步。执行后该年度期间锁定。反年结要另做并填原因 |

**人力与行政**

| 页面 | 要解释的项 |
|---|---|
| 人力资源 | 离职：账号和未结费用会怎样 |
| 租房、缴费、行政资产、车辆差旅 | 各单据里「提交之后还能不能改」的状态字段 |

**数据与系统**

| 页面 | 要解释的项 |
|---|---|
| 数据资产 | 授权范围、有效期、脱敏等级。到期后自动失效，不会延续 |
| 自动化 | 失败是否重试、这次执行会不会写凭证 |
| 设置 | 品牌、字典、参数改完会影响哪些页面 |

名称、备注、普通日期、电话、地址，不放标记。日期只有在它决定账龄、折旧起点、免征区间或锁定期时才放，并在浮层里写它决定什么。

### 6.2 指标卡

经营看板和指标中心的每张卡，标记在卡片右上角。浮层写：这个数的期间、包不包括草稿、和报表不一致时以哪边为准。卡内不再写第二行教程。

### 6.3 表头

列名是行话时，标记在表头文字右侧，不在每个单元格里重复。例如：计费模式、账龄、可抵扣税额、预算基线。编号、名称、金额、状态、日期这类列名不标记。

点表头标记只解释这一列，不解释整张表。

### 6.4 按钮

看名字看不出后果的按钮，标记仍在**这个按钮的右上角**，压住按钮圆角外侧 6px。点开只回答：点下去发生什么、什么时候点不了、能不能撤销。不超过 4 行。

必须有标记：同步到外部系统、提交审批、确认底稿、结转、反结转、年结、作废、红冲、终止、处置、减值、新增授权、覆盖导入。

没有标记：保存、取消、关闭、新建、编辑、查看、搜索、导出当前列表。删除不靠标记解释，确认框里写清对象和后果。

## 7. 和当前弹窗的差别

当前纳税主体弹窗要按第 5 节改，其它布局不动：

- 去掉标题行的「说明」。
- 编码、统一社会信用代码、纳税人类型、默认销项税率、默认进项税率、城建税率、申报周期、小型微利企业，每一项标签行右端加标记。
- 名称不加。
- 字段下的短结果句保留。
- 宽 720、三分区、底部取消和保存，保持现在这样。

全站已经加上的页面级「说明」和按钮角标，页面级的撤掉，改成落到具体项上。按钮角标保留。合同税率、发票税率、年结、确认底稿、数据授权这些已经写过的句子，拆进对应的项，不删内容。

## 8. 验收

纳税主体弹窗：

- 标题行没有「说明」，只有关闭。
- 第 5 节表格里标了「有」的项，标签行右端都能点到 28×28 的标记。
- 点「小型微利企业」只出现这一项的三句，不出现其它字段的口径。
- 点「城建税率」能看到 7 / 5 / 1 和「留空不是 0」。
- 名称没有标记。
- 字段下没有超过一句的说明，界面上没有 `**`。

全站抽查：

- 合同、发票、项目、资产、税务申报、年结、数据授权：每个会改变税额或期间的字段都有自己的标记。
- 这些页面的标题行没有总说明。
- 经营看板每张指标卡右上角有标记。
- 表头标记不会出现在该列的每一行里。
- 保存和取消上没有标记。

## 9. 实施顺序

确认本需求后再改界面。

1. 做一个「项说明」组件：标签行右端的标记加 280px 浮层。纳税主体弹窗按第 5 节改完并验收。
2. 去掉全站标题行上的总说明，把其中的句子拆到对应字段、指标卡或按钮上。
3. 按第 6.1 节的表，从合同、发票、项目、资产开始铺字段标记，再铺财务其余页面。
4. 看板指标卡和行话表头用同一个组件。
5. 按钮角标保持，不和项说明混用。
