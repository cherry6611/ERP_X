## 三、项目内部关联与联动

### 3.1 总体结论

**板块之间已形成真实的、代码级的数据联动**，不是各自孤立的 CRUD。核心链路如下：

### 3.2 已核查的联动链路

```
CRM 线索/商机 → 合同（合同金额进 BI 合同额指标）
   → 项目（合同转项目；合同里程碑 → 项目里程碑 → 收入确认）
   → 成本归集：
       · 工时确认：小时 × 人员费率 → 项目成本（兼职工单列 flex_labor 类型）
       · 采购订单 → 项目成本
       · 费用报销审批通过 → 项目成本
   → 收入确认（项目收入 + 收入调整）→ 毛利 = 确认收入 − Σ项目直接成本
   → 应收/应付独立记账（含核销、发票、收/付款）→ BI 汇总
   → 全部写操作 → 全局审计日志
```

- 毛利口径在项目详情页与经营看板（BI）保持一致，均为「确认收入 − Σerp_project_cost」。
- 人力资源联动：工时填报 → 成本确认 → 工资单按当月确认工时的项目占比分摊（详见第四章）；请假、考勤与员工档案联动。
- 行政板块联动：租房合同到期自动流转状态并触发提醒（触发器激活后生效）；行政缴费/资产/车辆差旅独立管理。
- 合规板块：审计日志覆盖全模块写操作；数据资产模块管理数据集与授权。

### 3.3 存在的两个口径断点（数据在、流程在，但未计入毛利）

1. **工资单分摊不进毛利**：工资单审批通过后，按当月已确认工时的项目占比分摊写入成本分摊账（erp_cost_allocation，类型 labor），但毛利公式只汇总项目成本表（erp_project_cost），固定薪酬目前不影响任何项目的毛利。
2. **折旧与行政支出同样在毛利之外**：固定资产折旧进分摊账但不进项目成本；行政缴费（房租水电等）完全不进财务口径。

> 这两个断点不是流程缺陷，而是「直接成本 / 期间成本」的口径分界问题，正是第四章要界定的内容。

## 四、人力资源板块：固定薪酬成本核算界定与建议

### 4.1 现状

- 人力资源板块包含固定薪酬（hr_payroll 工资单：基本工资、绩效工资、津贴、社保、公积金、个税、实发工资，按「员工 + 月份」唯一）。
- 工资单审批通过后，系统按该员工当月**已确认工时的项目占比**，将净工资分摊写入成本分摊账（costType=labor），同时生成工资凭证草稿——即**固定薪酬已经做了按项目分摊的归集记账**。
- 但经营指标口径为：**毛利 = 确认收入 − Σ项目直接成本**，而固定薪酬分摊额不进项目直接成本表，因此固定薪酬目前事实上被当作「固定成本 / 期间费用」处理，不参与毛利。

### 4.2 界定建议

**固定人力成本应界定为期间成本（间接成本），不建议按项目归集进毛利。** 理由：

1. 固定薪酬服务于公司整体（人员编制存在与否不取决于某个项目），不满足「可直接归属到项目」的直接成本判定标准；
2. 若把固定薪酬写进项目成本，项目毛利将随人员编制、出勤结构波动而非随项目本身变化，项目之间不可比，毛利失去「衡量项目经营质量」的管理意义；
3. 现行系统结构（分摊账 erp_cost_allocation 与项目成本表 erp_project_cost 分离）与此口径天然一致，无结构性改动需求。

### 4.3 是否在营业额中先减固定成本再算毛利？

**不建议。** 推荐采用标准损益层次：

| 层次 | 公式 | 系统现状 |
| --- | --- | --- |
| 营业额 | 确认收入 | ✅ 已有 |
| 毛利 | 营业额 − 直接成本（工时折算人力、外包、采购、差旅等） | ✅ 已有，保持不变 |
| 营业利润 / 净利 | 毛利 − 期间费用（固定薪酬 + 房租水电 + 折旧摊销） | ⚠️ 数据都在（分摊账 + 行政缴费），尚未在 BI 汇总展示 |

- 先减固定成本再算毛利，得到的是「贡献毛益」口径——它有价值，但应作为**新增管理指标**，而不是替换毛利定义。
- 建议新增指标：**项目贡献净额 = 项目毛利 − 分摊固定成本**（工资单分摊、折旧分摊数据已存在于分摊账，纯展示层即可支撑）。用途：
  - 评估项目真实盈利（扣除摊入的固定人力后是否仍为正）；
  - 报价决策：毛利保报价下限、贡献净额保现金流下限；
  - 人力编制决策：固定薪酬总额与贡献净额总量的匹配关系。

### 4.4 当前处理方式结论（直接回答）

| 问题 | 结论 |
| --- | --- |
| 固定薪酬产生的人力成本如何界定？ | 期间成本 / 间接成本；按月分摊记账（系统已实现），不进单个项目成本 |
| 需要归集成本、按项目分摊，还是直接计入固定成本？ | 分摊记账照做（供管理与考核用），但不计入项目毛利口径 |
| 是否应在营业额中先减固定成本再算毛利？ | 否。毛利 = 营业额 − 直接成本；固定成本在利润层面扣除；如需该视角，新增「项目贡献净额」指标 |

### 4.5 可选代码增强清单（本轮不实施，供后续排期）

1. BI 经营看板新增「期间费用」卡片：按月汇总固定薪酬分摊（分摊账 labor）、折旧分摊、行政缴费；
2. BI / 项目详情新增「项目贡献净额」指标：项目毛利 − 该项目分摊固定成本（数据源：分摊账）；
3. BI 新增「营业利润」指标：公司级毛利 − 期间费用合计。
