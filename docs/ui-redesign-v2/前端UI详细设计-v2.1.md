> 基于《前端UI重设计方案 v2》细化  
> 新增已确认决策：**操作提示统一放在操作组末尾，使用独立 `?` / `ActionHelp`**
>
> 状态：详细设计稿，未改业务代码  
> 日期：2026-10-19

## 1. 已确认的设计决策

### 1.1 提示按钮位置

不在按钮右上角做小角标。

```text
[ 主操作 ]  [ 次操作 ]  [ 更多 ]        ?
```

- 一个操作组只放一个 `?`
- `?` 放在操作组末尾，与按钮间隔 8px
- 视觉尺寸 16px，可点击区域 32×32
- hover / focus / click 打开 Popover
- 只给“结果不直观 / 有前置条件 / 高风险”的操作配置
- 保存、取消、新增、导出等常规操作不配置

### 1.2 提示分层

| 层 | 组件 | 用途 |
|---|---|---|
| 页面层 | NoticeBar | 阻塞性前置条件、需要持续可见 |
| 操作层 | ActionHelp | 解释某个操作做什么、有什么影响 |
| 字段层 | FieldHelp | 字段口径、取值规则 |
| 结果层 | Toast | 保存成功、同步完成 |
| 上下文层 | Drawer | 记录详情、附件、日志、通知 |
| 决策层 | Dialog / AlertDialog | 短确认、短表单、危险操作 |
| 页面级表单 | Form Page | 超过 7 个字段的复杂表单 |

### 1.3 视觉方向

**Quiet Ledger / 安静的账本**

- 一个主任务
- 一个主操作
- 一条页面级提示
- 细边框、少投影、低饱和
- 列表优先，详情在右侧，表单向文档

## 4. 核心组件

### 4.1 ActionHelp

#### 结构

```text
[ 登记合同 ]  [ 同步到多维表格 ]  [ 更多 ]     ?

点击 ?：
┌─────────────────────────────────┐
│ 同步到多维表格                   │
│ 将合同数据写入飞书多维表格；      │
│ 已同步成功的记录会自动跳过。      │
│                                 │
│ 查看说明 →                      │
└─────────────────────────────────┘
```

#### 规格

| 项 | 值 |
|---|---|
| 图标 | `CircleHelp` 16 |
| 视觉尺寸 | 16 |
| 点击区域 | 32×32 |
| 颜色 | `text-muted` |
| hover | `text`，背景 `#F1F2F6` |
| 浮层宽度 | 320 |
| 浮层内边距 | 14 |
| 标题 | 13 / 600 |
| 正文 | 12 / 18 |
| 最大行数 | 4 |
| 底部链接 | 可选 |
| 触发 | hover 120ms / focus / click |
| 键盘 | Enter/Space 打开，Esc 关闭 |
| ARIA | `aria-label="查看操作说明"` |

#### 放置条件

必须有：

- 同步、批量处理
- 提交审批
- 结转、反结转
- 作废、终止
- 导入、覆盖
- 数据授权

不配置：

- 保存
- 取消
- 新增
- 编辑
- 搜索
- 导出 Excel
- 查看详情

#### 一页规则

- 一个操作组最多一个 `?`
- 页面内最多两个 `?`
- 如果操作超过 4 个，先收进“更多”，`?` 仍在组末尾
- 破坏性操作不靠 `?` 解释；确认弹窗里必须写清楚后果

### 4.2 NoticeBar

```text
[!] 还没有纳税主体，提交审批前需要先创建。   [去创建]  [×]
```

- 高度 40~44
- 左侧 16px 图标
- 正文 12/18
- 右侧一个文字按钮
- 可关闭，按 session 记忆
- 同一页面最多一条
- 阻塞性才使用；普通说明不用

### 4.3 FieldHelp

```text
税率（%）  ?
```

点击：

```text
税率按纳税主体默认档位带出。
小规模主体可选 1% / 3%，一般纳税人可选 6% / 9% / 13%。
```

- 问号 14
- 点击区域 24
- Popover 280
- 正文 12/18
- 不写长段落

### 4.4 DetailDrawer

```text
┌──────────────────────────────────────┐
│ 合同详情  CT202610001   [已生效]   × │
├──────────────────────────────────────┤
│ 客户 / 金额 / 负责人 / 签订日期       │
│                                      │
│ 概览  明细  附件  变更  日志          │
│                                      │
│ 内容                                 │
│                                      │
├──────────────────────────────────────┤
│ [关闭]                    [编辑] [提交]│
└──────────────────────────────────────┘
```

- 详情 640px
- 复杂 800px
- 标题 16/600
- 摘要 2×2 或 4×1
- Tab 13
- 底部操作栏 64
- 内容独立滚动
- 打开时保留列表滚动位置

### 4.5 Dialog

| 类型 | 宽度 | 场景 |
|---|---|---|
| Confirm | 440 | 删除、终止、作废 |
| Quick Form | 560 | 3~6 字段 |
| Large | 720 | 快速编辑 |
| Import | 800 | 批量导入预览 |

统一：

- 圆角 16
- padding 24
- 标题 16/600
- 描述 12/18
- footer 64，右对齐
- 关闭按钮右上

### 4.6 Form Page

```text
┌──────────────────────────────────────────┬────────────────┐
│ 基本信息                                 │ 填写提示        │
│ 合同名称 *  [____________________]       │ · 税率口径      │
│ 客户 *      [____________________]       │ · 附件要求      │
│ 金额 *      [____________________]       │                │
│                                          │ 当前状态        │
│ 履约信息                                 │ 草稿            │
│ 签订日期    [________]                   │                │
│ 开始日期    [________]                   │                │
```

- 主表单 2/3，右侧 1/3
- 右侧只放提示、状态、附件、关联记录
- 底部吸底 64
- 字段 label 在上，13/500
- 必填用主色 `*`，不用红色
- 错误在字段下方 11px
- 不把说明堆在页面顶部

### 4.7 表格

- 表头 11/16，背景 `#FAFBFC`
- 行高 52
- 行 hover `#FAFBFF`
- 选中行 `primary-soft`
- 金额右对齐、等宽
- 状态 Badge 固定宽度
- 操作列最多两个文字按钮 + `…`
- 分页在右下
- 表格外不套卡片；用 1px 边框和 12px 圆角
- 空态高度 160，一句说明 + 一个动作

### 4.8 Toast

- 右上
- 宽 360
- 图标 + 标题 + 可选描述
- 成功 3s，失败 6s
- 同一时间最多 3 条

### 4.9 通知 Drawer

- 从铃铛打开
- 宽 420
- 标题“待办与预警”
- 分类：全部 / 应收逾期 / 授权到期 / 资产报废
- 每条：类型 Badge + 标题 + 编号 + 时间
- 底部“查看全部”
- 不再在看板内占用一张大卡

## 5. 页面模板

### 5.1 列表页

```text

[可选 NoticeBar]
工具条：搜索 / 筛选 / 视图 / 导出 / 列设置

```

规则：

- 主操作唯一
- 工具条与表格同宽
- 筛选最多一层
- 批量选择后出现底部批量条

### 5.2 详情页

```text
面包屑
标题 + 状态 + 操作 + ?
摘要 4~6 项
Tabs
主内容 2/3 + 右侧上下文 1/3
```

右侧：

- 状态
- 关联合同/项目
- 负责人
- 附件
- 最近操作

### 5.3 表单页

- 文档式分区
- 两栏
- 右侧提示
- 吸底操作
- 未保存离开确认

### 5.4 报表页

```text
标题 + 期间 + 主体
口径摘要（一行）
校验 chip（通过 / 差异）
筛选
报表主表
```

- 筛选一层
- 口径用 Popover
- 差异用 Drawer
- 数字右对齐
- 导出是次操作

### 5.5 设置页

- 左侧子导航 200
- 右侧内容 880
- 每组一张卡
- 组内保存
- 不铺满全宽

### 5.6 看板

- 指标 4
- 趋势 2/3 + 待办 1/3
- 待办最多 5 条
- 更多进 Drawer
- 不放说明卡

## 8. 交互状态

### 8.1 按钮

- default
- hover：背景深 4%
- active：深 8%
- focus：2px 主色外圈
- loading：图标替换为 spinner，文字保留
- disabled：40% 透明，不改变布局

### 8.2 表格

- loading：6 行骨架
- empty：160px 空态
- error：内联错误 + 重试
- selected：主色浅底
- hover：`#FAFBFF`

### 8.3 抽屉

- 打开：右侧滑入 200ms
- 关闭：滑出 160ms
- 遮罩：`rgba(15,23,42,.32)`
- Esc 关闭
- 点击遮罩关闭（表单有未保存时确认）

### 8.4 弹窗

- 缩放 0.98 → 1
- 遮罩 0.32
- 危险操作主按钮红色

| 1024~1279 | 68 折叠栏，标题 22，工具栏换行 |
| <1024 | 侧栏 Drawer，表单单列，操作吸底 |

最低适配 1280。

## 10. 可访问性

- 所有 icon-only 按钮有 `aria-label`
- `ActionHelp` 支持 Enter/Space/Esc
- Dialog/Drawer 焦点锁定
- 表单错误 `aria-describedby`
- 对比度 ≥ 4.5:1
- 状态不只依赖颜色
- 键盘可完成搜索、详情、保存、关闭


- 优先复用现有 `Dialog / Sheet / Popover / AlertDialog`
